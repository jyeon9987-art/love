# 다시, 우리 💌

카카오톡 대화 기반 AI 재회 분석 서비스 (목업 / MVP)

## 주요 기능
- 카톡 대화 붙여넣기 → AI 분석 시뮬레이션
- 재회 가능성 점수, 상대방 심리 키워드, 말투 패턴 분석
- **MBTI 기반 궁합 분석** (16가지 유형별 맞춤 공략 포인트)
- 무료 1차 분석 + 유료 심층 분석 (Freemium)

## 실행 방법
`index.html` 파일을 더블클릭해서 브라우저에서 열면 끝.

## 기술
- HTML / Tailwind CSS (CDN) / Vanilla JS
- 외부 의존성 없는 단일 파일 구조

## 배포
GitHub Pages를 통해 무료 배포됩니다.
